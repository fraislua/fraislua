# AIサブスクリプションの利用枠をAPI価格で並べる（まとめ）

> 要約: 月額$20前後のAIサブスクリプション2つ（Claude Pro、Google AI Pro）について、これまでに計測した利用量をAPI定価に換算して並べる。Claude Code側は控えめに見積もっても月あたり約$2,700相当以上、Antigravity側は多く見積もっても約$525相当だった。ただし両者は計測方法も、プランに含まれるものの範囲も異なる。この数字が示すのは「コーディングエージェント用の枠をAPI価格で測った大きさ」であり、プラン全体の優劣ではない。

## この記事の位置づけ

個別の計測は次の2本の記事にまとめている。本記事はその結果を並べ、何が言えて何が言えないかを整理するものである。

- [Claude Codeの実測トークン量から見るコストパフォーマンス](./04_claude_code_token_cost_analysis.md)
- [Antigravityの5時間枠1回分をAPI価格に換算する](./05_antigravity_quota_cost_analysis.md)

ChatGPT Plus（Codex）は計測していないため、本記事には含めていない。

## 並べた結果

| 項目 | Claude Pro（Claude Code） | Google AI Pro（Antigravity） |
|---|---|---|
| 月額 | $20 | $19.99（日本では2,900円・税込） |
| 計測の根拠 | 約30日間の利用実績（Usage画面） | 5時間枠1回分のログを週次上限まで外挿 |
| 使用モデル | Sonnet5 / Opus5 | Gemini 3.8 Flash / 3.7 Flash |
| 入力・出力の換算額 | 約$704 | 約$350〜375 |
| キャッシュ分の換算額 | 約$2,000以上 | 約$150 |
| 合計 | 約$2,700以上 | 約$500〜525 |
| 数字の性質 | 下限（控えめな見積もり） | 上限（枠を毎週使い切った場合） |

Claude側は下限、Antigravity側は上限として出している。それでも約5倍の差があるため、「API価格で測った利用枠はClaude Codeのほうが大きい」という大小関係は、見積もりの誤差では覆らないと考えている。

## Claude Code側の見積もり

### 入力・出力

約$704は、[04の記事](./04_claude_code_token_cost_analysis.md)で算出した値である。Usage画面に表示されたモデル別の入力・出力に、Sonnet5（$2/$10）とOpus5（$5/$25）の単価を乗じている。

### キャッシュ

04の記事の追記に書いた通り、Usage画面の合計トークン数は途中からキャッシュ分を含むようになったとみられる。9月中旬時点の直近30日では合計10.7B、入力・出力の合算は約46.2Mで、差の約10.65Bがキャッシュ分にあたる。

このキャッシュ分を、次のように控えめに換算した。

- 全量を、単価が最も安いSonnet5のキャッシュ読み取り（$0.20/M）で計算する: 10.65B × $0.20/M ≒ 約$2,130
- この期間にFableモデルを追加クレジット（約$85分）で利用していたため、その分を差し引く: 約$2,045

これを約$2,000以上としている。

### 控えめな見積もりにしている理由

この約$2,000は、次の理由でいずれも実際より小さく出る方向に置いている。

- キャッシュへの書き込みは読み取りの12.5倍の単価だが、内訳が分からないため全量を読み取りとして扱っている
- 実際にはOpus5も半分程度使っており、そのキャッシュ読み取り単価は$0.50/MとSonnet5の2.5倍である
- Usage画面の数字はデスクトップPC上での利用を集計したもので、それ以外の環境での利用分は入っていない

一方で、この数字には不確かな点もある。

- 合計トークン数からの引き算で求めた推定値であり、キャッシュ分として画面に表示されている数字ではない
- 入力・出力の約$704（8月上旬〜9月上旬）とは集計期間が一致していない
- 集計期間の大半は、週間利用制限+50%増キャンペーンの適用中だった
- 追加クレジットで利用した分のトークンが合計に混ざっており、約$85の差し引きはその補正である

このため、合計値そのものは参考値として扱い、「少なくともこの程度」という下限としてのみ使っている。

## Antigravity側の見積もり

約$500〜525は、[05の記事](./05_antigravity_quota_cost_analysis.md)で算出した値である。5時間枠1回分（約$19.4〜20.3）を、UIに表示された週次上限の消費率（1枠で16.66%）から週6枠・月4.3週に外挿している。

こちらは枠を毎週すべて使い切った場合の値であり、実際の利用額はこれより小さくなる。キャッシュ読み取り分はすでに含まれている。

## プランに含まれるものの範囲

ここまでの比較は、コーディングエージェントの利用枠だけを取り出したものである。プラン全体として見ると、前提が異なる。

AntigravityはGoogle AI Proに含まれる機能の1つに過ぎない。同じ月額には、Geminiアプリの上位モデルやDeep Research、NotebookLMの拡張、5TBのストレージなども含まれている。Antigravityの換算額が小さいことは、Google AI Proというプランの価値が小さいことを意味しない。

Claude Proも同様に、Claude Code以外の通常のチャット利用を含むプランである。今回の計測はClaude Codeでの利用に限っており、プラン全体の利用量を測ったものではない。

つまりこの比較から言えるのは、「コーディングエージェントを主目的に契約する場合、API価格で測った枠はClaude Proのほうが大きい」というところまでである。

## 換算額をどう読むか

換算額の差には、利用量の差と単価の差の両方が含まれている。

| 項目 | Claude Code | Antigravity |
|---|---|---|
| 月あたりのトークン量（キャッシュ込み） | 約10.7B | 約2.4B |
| キャッシュ読み取り単価（$/M） | $0.20〜0.50 | $0.075 |
| 入力単価（$/M） | $2〜5 | $0.75 |
| 出力単価（$/M） | $10〜25 | $3.75 |

トークン量の差は約4〜5倍、単価の差は約3〜7倍である。Flashは単価の安いモデルであるため、同じ量の作業をしても換算額は小さく出る。換算額は「API従量課金で同じことをした場合にいくらかかるか」を示す指標であり、こなせる作業量や成果物の質を直接表すものではない。

また、いずれの金額も相対的な経済性の指標であり、その額の現金価値を得ているという意味ではない。

## 残っている課題

- Antigravityの枠がAPI価格に比例して消費されるのかは、公式には確認できていない
- Claude側のキャッシュ分は、読み取りと書き込みの内訳、モデル別の内訳が分かれば見積もりを絞り込める
- ChatGPT Plus（Codex）は未計測である
- 同じ作業を同じ計測方法で両方に流す比較は行っていない

---

※本記事の数値は、2026年8月〜10月上旬に計測した利用量と、2026年10月上旬時点の各社API価格・プラン条件に基づく。Claude側は控えめな下限、Antigravity側は枠を使い切った場合の上限として算出しており、同じ精度の実測同士を比較したものではない。価格改定や利用制限の変更により数値は変動しうる。
